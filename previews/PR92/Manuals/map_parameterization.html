This includes the ability to create sparse maps, which can be particularly beneficial in high-dimensional settings or when the underlying relationships are known to be simpler. Example: Comparing Map Parameterizations ​

We optimize the coefficients of each map to match a cubic target density. The target density is defined as:

where is the standard normal PDF.

Define the cubic target density and visualize it:

julia
logtarget(x) = logpdf(Normal(), x[1]) + logpdf(Normal(), x[2] - x[1]^3 - x[1]^2)

We create the MapTargetDensity and quadrature weights for optimization:

julia
target = MapTargetDensity(logtarget)
quadrature = SparseSmolyakWeights(3, M_to)

Generate samples in the standard normal space for the variance diagnostic:

julia
samples_z = randn(1000, 2)

Now, we optimize each map type, compute the variance diagnostic and visualize the mapped samples.

Total Order Map ​

We start with the total order map:

julia
optimize!(M_to, target, quadrature)

mapped_samples = evaluate(M_to, samples_z)
var_diag = variance_diagnostic(M_to, target, samples_z)
println("Variance Diagnostic: ", var_diag)
Variance Diagnostic: 1.167843439866085e-16

No Mixed Terms Map ​

Next, we optimize the no-mixed-terms map:

julia
optimize!(M_nm, target, quadrature)

mapped_samples_no_mixed = evaluate(M_nm, samples_z)
var_diag_no_mixed = variance_diagnostic(M_nm, target, samples_z)
println("Variance Diagnostic: ", var_diag_no_mixed)
Variance Diagnostic: 9.651700844668678e-17

Diagonal Map ​

Finally, we optimize the diagonal map:

julia
optimize!(M_d, target, quadrature)

mapped_samples_diagonal = evaluate(M_d, samples_z)
var_diag_diagonal = variance_diagnostic(M_d, target, samples_z)
println("Variance Diagnostic: ", var_diag_diagonal)
Variance Diagnostic: 0.09872800975991755

We observe that the total order and no-mixed-terms maps achieve similar variance diagnostics, while the diagonal map performs significantly worse due to its inability to capture dependencies between variables.

Adaptive Map Construction

The choice of map parameterization can significantly impact the performance of transport maps. In practice, one might start with a simpler map structure, such as the diagonal or no-mixed-terms map, and then adaptively enrich the map based on the observed performance, as discussed in [4]. This adaptive approach allows for a balance between computational efficiency and approximation accuracy. For more information see the Adaptive Transport Maps manual and [4].
