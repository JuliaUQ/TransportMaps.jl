Composing Maps ​

Composing maps allows a combination of simple transformations into a more flexible transport. ComposedMap chains fixed coordinate transformations and fitted maps, providing evaluation, inversion, and density calculations for the complete composition.

Constructing and Evaluating a Composition ​

Constructor arguments follow evaluation order: the first map is applied first. Construct the layers separately, then combine them:

julia
linear = LinearMap([1.0, -1.0], [2.0, 3.0])
correction = PolynomialMap(2, 2)
C = ComposedMap(linear, correction; forwarddirection = :reference)

x = [0.2, -0.4]
z = evaluate(C, x)          # correction(linear(x))
x_recovered = inverse(C, z) # inverse layers in reverse order

These constructors initialize the maps. Fit the polynomial layer separately using the procedures in Optimization. ComposedMap uses the supplied layers and their current parameters.

Matrices contain one observation per row:

julia
X = [0.2 -0.4; 0.5 0.1]
Z = evaluate(C, X)
X_recovered = inverse(C, Z)

Tuples, vectors, and nested compositions are also accepted: ComposedMap((linear, correction)), ComposedMap([linear, correction]), and ComposedMap(ComposedMap(linear), correction) have the same evaluation order. Layers must have matching dimensions and compatible supports. LinearMap() is a dimension-free identity.

Fixed Coordinate Transformations ​

The following maps can be used as fixed layers alongside fitted polynomial maps:

MapForward transformationTypical use
LinearMap  Componentwise centering and scaling
LaplaceMap  Whitening with a full covariance or a Laplace approximation
PriorMap Reference-to-prior transformation for independent continuous marginals

LinearMap and LaplaceMap ​

LinearMap accepts means and standard deviations directly, as above, or estimates them from samples. LaplaceMap also accounts for correlations:

julia
samples = [0.5 1.0; 1.5 -0.5; 2.0 0.5; 3.0 1.5; 2.5 -1.0]
standardization = LinearMap(samples)
whitening = LaplaceMap(samples)
whitened_map = ComposedMap(whitening, correction; forwarddirection = :reference)

LaplaceMap(target, initial_point) instead finds the mode of a MapTargetDensity and estimates covariance from its log-density Hessian. For an unnormalized target , the Laplace approximation is

The Hessian must be positive definite at the fitted mode. Factoring   gives the forward whitening map   . The target's normalizing constant is not needed. For example, the following Gaussian target has mode   and covariance , so its Laplace approximation is exact:

julia
target = MapTargetDensity(x -> -(x[1] - 1)^2 / 2 - (x[2] + 0.5)^2 / 8)
density_whitening = LaplaceMap(target, [0.0, 0.0])
laplace_chain = ComposedMap(density_whitening, correction; forwarddirection = :reference)

Both maps standardize in their forward direction; inverse returns to the original coordinates. Standardization alone need not make a non-Gaussian density Gaussian.

PriorMap ​

PriorMap accepts a vector of independent continuous prior marginals. For their CDFs and reference CDF , it evaluates  . Its inverse transforms physical prior coordinates to reference coordinates:

julia
prior = PriorMap([LogNormal(0.3, 0.7), Uniform(0.4, 1.2)])
physical_point = evaluate(prior, [0.0, 0.0])
reference_point = inverse(prior, physical_point)

The default reference is Normal(). Choose a different continuous univariate reference with the keyword; it is repeated independently in every dimension:

julia
uniform_prior = PriorMap(
    [LogNormal(0.3, 0.7), Uniform(0.4, 1.2)];
    reference = Uniform(0, 1)
)

To combine a reference-space correction with the physical prior map , apply the correction first, then the prior transformation:

julia
physical_map = ComposedMap(correction, prior; forwarddirection = :target)
parameters = evaluate(physical_map, [0.0, 0.0])

The correction's output must lie within the prior map's reference support. In particular, a bounded reference requires a correction that preserves that support. Out-of-support inputs to PriorMap throw DomainError.

Direction and Density Evaluation ​

forwarddirection specifies the endpoints of the whole composition:

  • :reference: target to reference; sampling uses inverse.

  • :target: reference to target; sampling uses evaluate.

The keyword does not reverse any layer. If omitted, directions are inferred from layer metadata and must agree; linear-only chains default to :reference.

The reference density is taken from the last layer with reference metadata for :reference, or the first such layer for :target. Linear-only chains use a product standard normal. Set the reference explicitly when needed:

julia
C_with_reference = ComposedMap(
    linear, correction;
    forwarddirection = :reference, reference = Normal()
)

pdf and logpdf always evaluate the target-density approximation at target coordinates. jacobian returns the forward determinant, and logabsdetjacobian accumulates layer log-determinants:

julia
density = pdf(C, x)
log_density = logpdf(C, x)
determinant = jacobian(C, x)
log_determinant = logabsdetjacobian(C, x)

These operations also accept matrices of row-wise points. pullback(C, x) follows the package convention and is an alias for pdf(C, x). pushforward(C, target, z) evaluates a supplied target density in reference coordinates, including the change-of-variables Jacobian.

Adding a Fitted Correction ​

For an existing reference-to-target map , a new reference-space correction acts before the old map:   . In evaluation order, prepend it:

julia
T_new = ComposedMap(Q, T; forwarddirection = :target)

For a target-to-reference map , append a correction :

julia
