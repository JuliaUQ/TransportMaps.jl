TransportMaps.ComposedMap Type
julia
ComposedMap(maps...; reference = nothing, forwarddirection = :auto)
ComposedMap(maps::Union{Tuple, AbstractVector}; kwargs...)

Compose maps in evaluation order: ComposedMap(A, B, C) evaluates C(B(A(x))). Inversion applies the inverse layers in reverse order. Layers may be linear, polynomial, nested compositions, or custom maps implementing numberdimensions, evaluate, inverse, and jacobian(map, x) (the forward determinant). Evaluation and inversion accept vectors and matrices with observations in rows.

All layers must have the same dimension, except the dimension-free identity LinearMap(). An empty sequence is not allowed. Layers are stored in a tuple C.layers and are not copied; use deepcopy to freeze a fitted layer.

forwarddirection=:reference means target → reference; :target means reference → target. By default, infer the direction from layers having that property (they must agree), or use :reference for linear-only compositions. An explicit direction overrides layer metadata without changing evaluation.

reference is the density at the reference endpoint of the whole map. By default, use the last layer with reference metadata for :reference, or first for :target, falling back to a product standard normal. A univariate distribution is interpreted as a product reference. Inferred metadata follows changes to the underlying layers. Matching dimensions alone does not guarantee compatible layer supports; the caller must ensure this.

The existing ComposedMap(L::AbstractLinearMap, M::PolynomialMap) constructor and its .linearmap / .polynomialmap accessors remain supported. Density methods always use the direction of the whole composition.

Sequential updates

julia
S = ComposedMap(S_previous, R; forwarddirection = :reference) # R ∘ S_previous
T = ComposedMap(Q, T_previous; forwarddirection = :target)   # T_previous ∘ Q

This container composes fitted maps; it does not fit or freeze their parameters.

TransportMaps.PriorMap Type
julia
PriorMap(marginals::Vector{<:ContinuousUnivariateDistribution}; reference = Normal())

Fixed diagonal transport from a product of the continuous univariate reference distribution to independent continuous prior marginals. The reference defaults to Normal(); Uniform(0, 1) and Uniform(-1, 1) are also supported. evaluate(P, z)[i] = quantile(P.marginals[i], cdf(P.reference.densitytype, z[i])); inverse(P, x) transforms physical coordinates back to the reference. Vectors are single points; matrices contain observations in rows.

The marginal vector must be nonempty and is copied on construction. Marginals must implement the Distributions.jl density, CDF, and quantile interfaces. Discrete distributions and dependent priors are not supported. Log-tail probabilities are used to reduce tail cancellation; finite precision can still round extreme quantiles to support boundaries. Inversion at a boundary may return infinity; transformation inputs outside their source support throw DomainError. Derivatives are defined in the interior of the support. A target-directed composition assigns zero density outside the prior support and at boundaries whose inverse coordinates are infinite.

jacobian returns the forward determinant, following the map convention. logabsdetjacobian sums log-density ratios. ForwardDiff input derivatives use analytical scalar transformation derivatives, without differentiating quantiles or CDFs. Distribution parameters are fixed.

After fitting T to the posterior in prior-reference coordinates, use ComposedMap(T, P; forwarddirection=:target) to obtain a map into physical posterior coordinates. The output of T must lie in the support of P.reference.densitytype; polynomial corrections do not automatically preserve bounded supports. PriorMap is a transport layer, not a distribution.
