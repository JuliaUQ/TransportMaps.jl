Mathematical background ​

Start with the Introduction for the change-of-variables formula, triangular maps, and the density- and sample-based fitting objectives.

Transport maps are smooth, invertible transformations between probability distributions. Triangular maps build on the Rosenblatt transformation [1] and the Knothe–Rosenblatt rearrangement [2], and support sampling, density estimation, and variational inference [3].

This package implements monotone triangular transport maps following [3] and [4]. For an introduction, see [5]; for applications in structural health monitoring and Bayesian inference, see [6].

The manuals cover polynomial bases, quadrature rules, and optimization, including automatic differentiation through DifferentiationInterface.jl and multithreaded map evaluation.

Related implementations ​

  • ATM: Matlab code for adaptive transport maps [4]

  • MParT: C++-based library for transport maps [7]

  • TransportBasedInference.jl: Julia implementation of adaptive transport maps (ATM) and Kalman filters

  • SequentialMeasureTransport.jl: Julia implementation of transport maps from sum-of-squares densities [8]

  • Triangular-Transport-Toolbox: Python code for the triangular transport tutorial paper [5]
