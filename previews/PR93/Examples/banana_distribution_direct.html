Banana Distribution: Create a Distribution ​

This example demonstrates the convenience constructors of TransportMapDistribution, which allow you to build and fit a distribution in a single step without manually managing intermediate map objects.

We compare two approaches: fitting from sample data and fitting from a target density function, both using the "banana" distribution from earlier examples.

julia
using TransportMaps
using Distributions
using Statistics
using CairoMakie
using LaTeXStrings

julia
function generate_banana_samples(number_samples)
    latent_samples = randn(number_samples, 2)
    return hcat(
        latent_samples[:, 1],
        latent_samples[:, 1] .^ 3 .+ latent_samples[:, 2],
    )
end

target_samples = generate_banana_samples(1_000)

Method 1: Distribution from samples ​

The convenience constructor automatically:

  1. Optionally applies a linear transformation to standardize the data

  2. Creates and fits a polynomial transport map

  3. Wraps the result in a distribution object

All in a single call:
