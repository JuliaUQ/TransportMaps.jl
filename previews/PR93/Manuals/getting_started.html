Getting Started with TransportMaps.jl ​

Turn independent standard-normal draws into samples from a correlated Gaussian. In four steps, you will define a target, fit a map, generate samples, and check the result. For the concepts and notation, start with the Introduction.

Install and Load ​

Install the package and the distribution tools used in this guide:

julia
using Pkg
Pkg.add(["TransportMaps", "Distributions"])
julia
using TransportMaps, Distributions, Statistics

1. Define the Target ​

Our target is a two-dimensional Gaussian with zero mean, unit marginal variances, and correlation . Wrap its log-density in MapTargetDensity:

julia
gaussian = MvNormal(zeros(2), [1.0 0.8; 0.8 1.0])
target = MapTargetDensity(x -> logpdf(gaussian, x))

Pass a log-density

The callable must return the log of the target density. It may be unnormalized, which is useful for Bayesian posteriors.

2. Fit the Map ​

Create a two-dimensional map with polynomial degree one. Its defaults use a standard-normal reference, a Hermite-based expansion, and softplus rectification. Construct quadrature for that reference, then fit the coefficients:

julia
M = PolynomialMap(2, 1)
quadrature = GaussHermiteWeights(2, M)
result = optimize!(M, target, quadrature)

optimize! updates M in place. The returned result contains the solver's convergence information. You can reuse the fitted map to generate new samples.

3. Use the Fitted Distribution ​

Wrap the fitted map in TransportMapDistribution, then use the standard Distributions.jl interface to generate samples:

julia
fitted = TransportMapDistribution(M)
target_samples = rand(fitted, 1_000)

target_samples is a   matrix: each column is one sample. These are independent draws from the fitted approximation to the target. The wrapper uses the map's configured reference distribution and fitting direction.

Sample orientation

Distributions.jl uses samples in columns. Map-level batch operations such as evaluate and the map plotting functions use samples in rows.

In the figure above, the circular reference cloud becomes a tilted target cloud; the contours show the known Gaussian target density.

4. Check the Result ​

Evaluate the fitted log-density at a point:

julia
logpdf(fitted, [0.0, 0.0])
-1.327051441332118

Compare its mean and covariance with the Gaussian target defined in step 1:

julia
mean(fitted)
2-element Vector{Float64}:
  4.228204152378725e-11
 -4.228028583707086e-11

The mean should be close to [0.0, 0.0].

julia
cov(fitted)
2×2 Matrix{Float64}:
 1.0  0.8
 0.8  1.0

The covariance should be close to [1.0 0.8; 0.8 1.0]. Polynomial and composed maps compute statistics by reference-space quadrature. To choose a rule, pass quad, for example cov(fitted; quad = quadrature). See the distribution API for the full interface.

For a map-specific diagnostic, draw reference samples and evaluate the variance diagnostic. Here each row is one reference sample:

julia
reference_samples = randn(1_000, 2)
variance_diagnostic(M, target, reference_samples)
3.5038706905128014e-18

A value close to zero indicates little variation in the log-density mismatch at the sampled points. For this simple target, it should be small. This is a useful diagnostic, rather than a guarantee of accuracy over the entire domain.

Plot Your Map ​

The reference_target_plot result is shown at the top of this page. To reproduce it, install a Makie backend once:

julia
Pkg.add("CairoMakie")

Then load it and call reference_target_plot:

julia
using CairoMakie
fig = reference_target_plot(M, reference_samples; density = target)

mappingplot shows the transformation itself by mapping a regular grid. Here the grid becomes sheared, reflecting the correlation in the target:

julia
grid = range(-2, 2; length = 100)
fig, ax, plt = mappingplot(
    M, (grid, grid); gridlines = 9,
    axis = (; xlabel = "x₁", ylabel = "x₂", aspect = DataAspect()),
    figure = (; size = (400, 500))
)
