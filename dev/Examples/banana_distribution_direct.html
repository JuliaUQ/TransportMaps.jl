Banana Distribution: Create a Distribution ​

This example demonstrates the convenience constructors of TransportMapDistribution, which allow you to build and fit a distribution in a single step without manually managing intermediate map objects.

We compare two approaches: fitting from sample data and fitting from a target density function, both using the "banana" distribution from earlier examples.

julia
using TransportMaps
using Distributions
using Statistics
using CairoMakie
using LaTeXStrings

Sample generation ​

The target distribution is the banana-shaped density:

where is the standard normal PDF. Exact samples are generated by drawing independent   and setting   and   .

julia
function generate_banana_samples(number_samples)
    latent_samples = randn(number_samples, 2)
    return hcat(
        latent_samples[:, 1],
        latent_samples[:, 1] .^ 3 .+ latent_samples[:, 2],
    )
end

target_samples = generate_banana_samples(1_000)

Method 1: Distribution from samples ​

The convenience constructor automatically:

  1. Optionally applies a linear transformation to standardize the data

  2. Creates and fits a polynomial transport map

  3. Wraps the result in a distribution object

All in a single call:

julia
d_samples_adaptive = TransportMapDistribution(
    target_samples,
    [10, 10],  # Maximum polynomial order per dimension
    true;      # Use adaptive term selection
    use_linear_map = true,  # Standardize data first
    k_folds = 5,  # Cross-validation folds
)

println("Samples-based distribution created")

Method 2: Distribution from target density ​

When the target density is available, use quadrature-based fitting:

julia
logtarget(x) = logpdf(Normal(), x[1]) + logpdf(Normal(), x[2] - x[1]^3)
quadr = LatinHypercubeWeights(1000, 2)

d_density_adaptive = TransportMapDistribution(
    logtarget,
    quadr,
    27,   # Target number of polynomial terms
    true  # Use adaptive term selection
)

println("Density-based distribution created")
println("  Mean: ", mean(d_density_adaptive))
println("  Std:  ", std(d_density_adaptive))

Using the distributions ​

Both distributions provide the same interface for downstream tasks.

println("Generated 1000 samples from fitted distribution")

println("  Empirical std:  ", vec(std(samples_from_fit; dims = 2)))
